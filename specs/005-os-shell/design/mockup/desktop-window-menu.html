About this site

This is Alex Profir's CV, presented as a small operating system that runs in the browser. It was built spec first: every feature has a public spec, a reviewed design and tests that trace back to its requirements.

Open the CV as a page Source code, specs and history on GitHub

Keyboard shortcuts

Alt+Shift+M
Go to the menu bar
Alt+Shift+D
Go to the dock
Alt+Shift+N
Next window
Alt+Shift+W
Close window
Alt+Shift+H
Minimize window
Alt+Shift+F
Maximize or restore window
Alt+Shift+P
Move window
Alt+Shift+S
Resize window

On a Mac, use Option+Shift in place of Alt+Shift. In menus and the dock, use the arrow keys, Enter and Escape.
