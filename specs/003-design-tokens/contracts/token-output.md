# Contract: The `@cv/tokens` Package

**Feature**: [spec.md](../spec.md) | **Data model**: [data-model.md](../data-model.md) |
**Research**: [research.md](../research.md) (R9, R10, R11, R12)

Every later feature reads design values through this package and nowhere else (Constitution IV).
This contract fixes what they can rely on. The package is an npm workspace, linked by `npm ci`,
with no dependencies. Its `package.json` declares `"type": "module"` and:

```json
"exports": {
  ".": "./src/index.ts",
  "./tokens.css": "./src/tokens.generated.css"
}
```

## Import

```ts
import '@cv/tokens/tokens.css'; // once, where the site's global styles load
import { cssVar, typography, mediaQuery, tokenValue, durationMs } from '@cv/tokens';
import { tokenTypes, themeGroups, activeThemes, themeValues } from '@cv/tokens';
import type { TokenName, TokenType, CssVarTokenName, TypographyTokenName, BreakpointTokenName, DurationTokenName } from '@cv/tokens';
```

| Export | Kind | What it is |
|--------|------|------------|
| `cssVar(name)` | function | `'var(--token-…)'` for any token except a typography token |
| `typography(name)` | function | For a typography token, an object of eight `var()` strings: `fontFamily`, `fontSize`, `fontWeight`, `fontStyle`, `lineHeight`, `letterSpacing`, `textTransform`, `textDecoration`. Spread it into a `style` prop |
| `mediaQuery(name)` | function | For a breakpoint token, the media condition, such as `'(width >= 768px)'`, for `matchMedia` |
| `tokenValue(name)` | function | The active combination's value as CSS text, for APIs that can't read a variable, such as the Web Animations `easing` option |
| `durationMs(name)` | function | A duration token's active value in milliseconds, for the Web Animations `duration` option |
| `tokenTypes` | value | The description: every token name from both sources, and its type (FR-025) |
| `TokenName` | type | `keyof typeof tokenTypes` |
| `TokenType` | type | The 19 type strings: the 17 Penpot types, `duration` and `cubicBezier` |
| `CssVarTokenName` | type | `TokenName` without the typography tokens: what `cssVar` accepts |
| `TypographyTokenName`, `BreakpointTokenName`, `DurationTokenName` | types | The names of those kinds |
| `themeGroups` | value | Each theme group and its themes |
| `activeThemes` | value | Each group's active theme (FR-054) |
| `themeValues` | value | Every combination's resolved values, keyed by combination (`'mode/light + motion/standard'`), then by name |

`tokenTypes`, `themeGroups`, `activeThemes` and `themeValues` come from
`src/tokens.generated.ts`. The functions live in `src/index.ts`. Nothing in the package tells
which source a token came from (Key Entities).

## Reading tokens

In a style sheet:

```css
.card {
  padding: var(--token-space-4);
  color: var(--token-color-text-primary);
  box-shadow: var(--token-shadow-raised);
  font-size: var(--token-typography-body-font-size);
  transition: opacity var(--token-motion-duration-fast) var(--token-motion-easing-standard);
}

@media (--token-breakpoint-wide) {
  .card { padding: var(--token-space-8); }
}
```

In a component:

```tsx
<p style={{ ...typography('typography.body'), color: cssVar('color.text.primary') }} />
<div style={{ '--card-gap': cssVar('space.2') } as React.CSSProperties} />   // a local variable
const wide = matchMedia(mediaQuery('breakpoint.wide'));
el.animate(frames, { duration: durationMs('motion.duration.fast'), easing: tokenValue('motion.easing.standard') });
```

A name that doesn't exist fails before merge:

```text
src/card.tsx(4,26): error TS2345: Argument of type '"color.text.primray"' is not assignable to parameter of type 'CssVarTokenName'.
packages/web/src/card.css:3:10 unknown-token --token-color-text-primray: no token has this name
```

The first comes from `npm run typecheck`, the second from `npm run token-check` (research R12).

## Names

- **CSS name**: `--token-` and the token's name in lower case, with `.` and `_` replaced by `-`.
  `color.text.primary` becomes `--token-color-text-primary`.
- **Typography**: `typography.body` becomes eight properties, `--token-typography-body-font-family`,
  `-font-size`, `-font-weight`, `-font-style`, `-line-height`, `-letter-spacing`,
  `-text-transform` and `-text-decoration`. There's no single custom property for the whole
  token. All eight names exist. A part the token doesn't set isn't written, so its `var()` is
  invalid and the property inherits.
- **Breakpoints**: a token whose first name part is `breakpoint` is also a custom media query of
  the same name.
- **The namespace**: every custom property or custom media name starting with `--token-`
  belongs to tokens. Styles may define their own variables under any other name. Defining one
  under `--token-` is reported (FR-051).

## The CSS file

```css
/* Generated by npm run token-output from packages/tokens/penpot/tokens.json and
   packages/tokens/motion/tokens.json. Do not edit. */
:root {
  --token-border-thin: 1px;
  --token-breakpoint-wide: 768px;
  --token-color-base-ink: #1f1d1a;
  /* … every token of the active combination, sorted by name … */
}

@custom-media --token-breakpoint-wide (width >= 768px);
```

- `:root` holds the **active combination** (FR-054). Every combination's values are in
  `themeValues`. Applying another combination is the theme switching feature's work.
- No browser supports `@custom-media` natively yet. The site's CSS build must replace it
  (research R11).

## Values

How each resolved value is written in CSS, and in `themeValues` and `tokenValue`.

| Type | Written as |
|------|------------|
| `color` | as resolved: `#00000080` stays `#00000080`. `rgba(<hex>, <a>)` becomes `rgb(<r> <g> <b> / <a>)` (FR-019) |
| `dimension`, `spacing`, `sizing`, `borderRadius`, `borderWidth`, `fontSizes`, `letterSpacing` | a unitless number gets `px`. `px` and `%` stay. Arithmetic is already evaluated |
| `rotation` | the number with `deg` |
| `opacity`, `number` | as resolved |
| `fontFamilies` | a CSS family list: each family in double quotes, except the generic families (`serif`, `sans-serif`, `monospace`, `cursive`, `fantasy`, `math`, `system-ui`, `ui-serif`, `ui-sans-serif`, `ui-monospace`, `ui-rounded`), joined by `, ` |
| `fontWeights` | the number. A named weight becomes its number. ` italic` is dropped |
| `textCase` | the keyword, lower case |
| `textDecoration` | `none`, `underline`, or `line-through` for `strike-through` |
| `typography` | its parts as above. `font-style` is `italic` when the weight ends in ` italic`. `line-height` is a number, a percentage or a `px` length |
| `shadow` | each shadow as `[inset ]<offsetX> <offsetY> <blur> <spread> <color>`, lengths as above, joined by `, ` |
| `duration` | as resolved: `150ms` |
| `cubicBezier` | `cubic-bezier(<x1>, <y1>, <x2>, <y2>)` |

## Guarantees

1. **Every name code reads exists** (FR-026). In TypeScript the functions accept only names from
   the description, and in style sheets the check reports unknown names.
2. **The output matches its sources** (FR-005). Both generated files are rebuilt in memory on
   every run of the check, which fails with `stale-output` when the committed files differ.
3. **Every combination has the same names and types** (FR-023). So code reading a token works in
   every theme, including ones added later (FR-024).
4. **Motion tokens read like any other token** (FR-049). Moving a token between the sources under
   the same name changes nothing here.
5. **Values keep their meaning** (FR-019). Conversion only changes Penpot's form into CSS's, as in
   the table above.
